## Deployment Steps

### Backend (Render)

1. **Set Environment Variables in Render Dashboard:**
   ```
   GOOGLE_API_KEY=<your-new-google-api-key>
   MONGODB_URI=<your-new-mongodb-connection-string>
   JWT_SECRET_KEY=<auto-generated-by-render>
   FRONTEND_URL=https://your-app.netlify.app
   ```

2. **Update `render.yaml`:**
   - Replace `https://your-netlify-app.netlify.app` with your actual Netlify URL

3. **Deploy:**
   ```bash
   git push origin main
   ```

### Frontend (Netlify)

1. **Set Environment Variables in Netlify Dashboard:**
   - Go to Site settings → Build & deploy → Environment
   - Add: `VITE_API_URL=https://your-backend.onrender.com/api/v1`

2. **Deploy:**
   ```bash
   cd frontend
   npm run build
   # Or push to trigger automatic deployment
   ```

### Local Development

1. **Backend:**
   ```bash
   # Copy and edit .env
   cp .env.example .env
   # Edit .env with your credentials
   
   # Start backend
   uvicorn main:app --host 0.0.0.0 --port 5000 --reload
   ```

2. **Frontend:**
   ```bash
   cd frontend
   # Copy and edit .env
   cp .env.example .env
   # Edit .env: VITE_API_URL=http://localhost:5000/api/v1
   
   # Start frontend
   npm run dev
   ```

## Common Issues

### "Failed to fetch" Error
- Check `VITE_API_URL` is set correctly in Netlify
- Verify backend is running on Render
- Check CORS configuration includes your frontend URL

### "Connection Refused"
- Backend not running
- Wrong port configuration
- Firewall blocking connection

### CORS Errors
- `FRONTEND_URL` not set in Render
- Frontend URL doesn't match CORS allowlist
- Missing `https://` in URL

## Port Configuration

- **Backend (Render)**: Port 10000 (from Dockerfile)
- **Frontend (Netlify)**: Served via CDN
- **Local Backend**: Port 5000
- **Local Frontend (Vite)**: Port 5173
