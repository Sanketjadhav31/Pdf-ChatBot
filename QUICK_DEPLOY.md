## Deploy Now

### Step 1: Redeploy Frontend on Netlify

Your frontend will now automatically use the correct backend URL. Just trigger a new deploy:

**Option A: Via Netlify Dashboard**
1. Go to https://app.netlify.com
2. Find your site "pdfchatbot1"
3. Click "Deploys" → "Trigger deploy" → "Deploy site"

**Option B: Via Git Push**
```bash
git add .
git commit -m "Fix backend URL configuration"
git push origin main
```

### Step 2: Check Backend on Render

Make sure your backend is running:
1. Go to https://dashboard.render.com
2. Find "pdf-chatbot-backend" service
3. Check if it's deployed and running
4. Verify environment variables are set:
   - `GOOGLE_API_KEY`
   - `MONGODB_URI`
   - `JWT_SECRET_KEY`
   - `FRONTEND_URL=https://pdfchatbot1.netlify.app`

### Step 3: Test

After Netlify redeploys (takes ~2 minutes):
1. Visit https://pdfchatbot1.netlify.app
2. Try to register/login
3. Check browser console for errors

## If Backend Isn't Running

If your backend URL is different or not deployed yet:

1. **Find your actual Render URL:**
   - Go to Render dashboard
   - Copy your service URL (e.g., `https://your-service.onrender.com`)

2. **Update the backend URL:**
   - Edit `netlify.toml` line 8: Change the URL
   - Edit `frontend/.env.production`: Change the URL
   - Commit and push

## Troubleshooting

### Still seeing "Connection Refused"?
- Backend might not be deployed on Render yet
- Check Render dashboard for deployment status
- Verify the backend URL is correct

### CORS errors?
- Make sure `FRONTEND_URL` is set in Render
- Check backend logs for CORS errors
- Verify the URL matches exactly (no trailing slash)

### "Failed to fetch"?
- Backend might be sleeping (Render free tier)
- Wait 30 seconds for it to wake up
- Check backend health: https://pdf-chatbot-kktm.onrender.com/docs
